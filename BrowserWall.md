# BrowserWall

`BrowserWall` is a collection web browser based wallpapers that are modified forks of `wv2wall` by Superswan (see credits).

## The Collection

### modified wv2wall

see [modified-wv2wall](https://github.com/EliteDiamonHawk/wv2wall)

- forked wv2wall with minor feature additions

### chromiumwall

see [chromiumwall](https://github.com/EliteDiamonHawk/chromiumwall)

- expanded version to support chromium based browsers
- set to your default browser so that the wallpaper can share resources with it

### ultralightwall

see [ultralighwall](https://github.com/EliteDiamonHawk/ultralighwall)

- version that uses the ultralight framework instead of the resouce heavy wv2wall
